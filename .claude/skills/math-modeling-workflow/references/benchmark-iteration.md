# 优秀论文对比学习与迭代改进流程

> 经验来源：2025 国赛 C 题（NIPT 时点选择与胎儿异常判定）完整实战 + 赛后检索一等奖/优秀论文逐环节对比。
> 目标：让"跑完论文后上网找优秀论文对比、迭代改进"成为每次实战的可复用闭环。

## 一、为什么值得做

第一版模型可能"验收 11/11 全绿但方法平庸"（如本次：二次多项式 R²=0.059，GBDT AUC=0.729）。
优秀论文往往揭示：**更强的非线性模型（GAMM R²=0.401）、更贴合题目目标的优化建模（风险最小化）、更优的分类器（随机森林 AUC 0.89）**。
对比的价值不是追高指标，而是发现"建模取向"的差距：统计显著性 vs 临床风险目标。

## 二、检索渠道（有效顺序）

1. **高校获奖新闻**：搜"<年份> 高教社杯 数学建模 <题号> 优秀论文 获奖"——新闻稿常点名获奖学校的论文题目（本身就是模型的浓缩提示）。
2. **IEEE/ACM 会议论文**：赛题常被写成论文（"Optimizing NIPT Timing…GAMM"、"risk minimization model"）。Abstract 直接给出 R²/AUC/时点。
3. **技术博客**（知乎/CSDN/小红书）：搜"<年份> 国赛 C题 <题目关键词> 建模思路 完整代码"，常有具体指标（"F2 最优阈值 0.2500"、"OOF AUC=0.7424"）。
4. **GitHub**：搜"<题号> <主题> mathematical modeling / CUMCM"，可能有完整代码仓库（若 GitHub 域名受限，用搜索缓存/镜像站读摘要）。
5. **期刊评述**：《数学建模及其应用》次年刊登"赛题评述"，直陈参赛论文通病——**最好的"避坑清单"**。
6. **学术文献库（paper-search-mcp）**：arXiv / Semantic Scholar / Crossref / OpenAlex 等学术源检索赛题方法文献（如 `"two-stage stochastic programming crop planning CVaR"`），直接拿 DOI/arXiv id，可查可引、无博客指标水分；查到的论文用 `download_with_fallback` 下载深读。方法见 `paper-search-literature.md`。

注意：非官方博客指标参差（AUC 0.74~0.91 都有），要区分"严格 OOF 交叉验证"与"含样本内/再拟合"的评估口径，只信可复现口径。

## 三、对比矩阵模板（逐环节填）

| 环节 | 我们的方案（方法+指标） | 优秀方案（方法+指标） | 差距 | 改进动作 |
|---|---|---|---|---|
| Q1 关系建模 | 多项式 OLS R²=0.059 | GAMM R²=0.401 | R² 过低 | 加样条 GAM，个体级 R² 0.059→0.21 |
| Q2 分组/决策 | 四分位 + 生存 90% 分位 | K-means + 风险最小化目标 | 时点偏晚 | 把"风险最小"化为目标函数 |
| ... | ... | ... | ... | ... |

**关键判断：哪些差距该修，哪些是"已验证正确"可以保留。**
本次经验：三级判定框架、0.25 概率阈值、X 染色体浓度/GC 含量特征重要性排序，与多个获奖方案一致——**思路已被验证正确，不用改，写进论文即可**。

> **另加一行"整体篇幅"逐项对比**：正文页数 / 图表数 / 迭代表·对比表数 / 参考文献数——"字数偏少、图表单调、论据单薄"正是优秀论文评审常见吐槽点，量化后一目了然（实例见第七节）。

## 四、迭代改进的取舍原则

1. **改最痛的**：Q1 R²=0.059 是全论文最大硬伤 → 优先补 GAM 样条；Q4 AUC 量级差距 → 补随机森林对照。
2. **改动成本控制**：新增独立求解器（`solve_q1_gam.py`）跑出真实 JSON，再写进论文；不要在原求解器里打补丁破坏证据链。
3. **改后必须重跑全链**：重新 latex_check + acceptance（A3 会扫描新增 result_q*.json 顶层标量——确保论文覆盖，或顶层只放字典）。
4. **保留被验证的正确设计**：不被"更高指标"误导去推翻已被多方案佐证的框架。
5. **改进要可解释**：GAM 从 0.059→0.21 的收益要能在论文里说清"为什么"（非线性响应），不只是报数字。

## 五、留档要求（强制）

用户会核查，每次迭代必须留档：
1. **论文版本存档**：`output/paper/archive/v<N>/` 存每次提交版 `main.tex/main.pdf/latex_check.json`（v1 是初稿，v2 是改进版……）。
2. **优秀论文资料存档**：`output/analysis/benchmark_study.md`——获奖论文列表（含外链）、公开方案与指标、逐环节对比表、差距总结、参考来源。
3. **求解器与结果**：新增求解器 `code/solve_q*_*.py` + `result_q*_*.json` 记录进 run_manifest（P3/P5 各记一次）。

## 六、本次实战沉淀的具体经验（可直接复用）

1. **关系建模优先试 GAM/样条**，二次多项式 R² 会严重低估非线性关系。先用 Spearman/散点判断非线性，直接上 B 样条基或 pyGAM。
2. **"最佳时点/最佳方案"这类决策问题，题目若说"潜在风险最小"→ 建显式风险目标函数**（风险权重 早1/中3/晚5 之类），比统计分位数更贴合题意。
3. **分类任务类别不平衡**：报告 AUC 之外必补 PR-AUC；阈值策略报告 F1/F2 最优阈值 + 高召回阈值，别只默认 0.5。
4. **重复测量数据**：GroupKFold（按受试者分组）防泄漏是硬要求，审稿/评述点名的常见问题。
5. **特征重要性结论要有临床一致性**：报告里能对上临床直觉的特征排序（如 X 染色体浓度 > GC 含量 > BMI）比 AUC 更能加分。

## 七、2024-A 题（板凳龙）实战沉淀（数值/机理型题的另一类经验）

> 对比对象：A242 / A016 / A053 / A163 / A178 五篇优秀论文。主诉差距：①字数偏少；②图表不美观；③论据不充分；④解答过程跳跃；⑤求解方式可更精细。全部修复后，把可复用经验固化于此：

1. **篇幅体量对照**：优秀论文正文普遍 20+ 页、图表 8+ 张、迭代表/对比表 3+ 张、参考文献 6+ 篇。自查口径：每个问题的"模型建立/求解/结果分析"三小节是否各有 1–2 页实质论据；不足 → 扩充论据（分析、对比、灵敏度），而非凑字。

2. **论证性图表是论据充分的载体**：每个"关键判据/临界值/极值"必须配一张图或一张迭代表，不能只给一句话结论：
   - **判据过零图**：碰撞/可行性判据由负到正的零穿越定位（如穿透深度 vs 时间）；
   - **极值/分布图**：把手速率沿时间/空间分布并标出峰值（先粗扫定位、再窗口加密）；
   - **收敛/迭代过程图或表**：二分区间收缩、扫描步长加密收敛（两轮之间看结果是否稳定）；
   - **效应/偏差图**：近似 vs 精确（如固定弧长偏移在调头段把刚体板凳"压短"最多 14%）。

3. **解答过程要显式呈现，不能跳跃**：二分/扫描/迭代的**每一轮记入 result JSON**（步号、候选值、可行性、区间宽度），正文用迭代表列出。这正是"怎么求出来的"，优秀论文普遍有此表。

4. **数值交叉验证是 P7 最强验证手段**（同题同参数、数值可复现 → 直接对表）：
   - 本文 p_min=0.450336 m vs 优秀论文 0.450338 m → 偏差 ±0.02%；
   - 本文放大系数 1.6066（v_max=1.2449）vs 优秀论文 1.6048/1.2463 → 偏差 ±0.11%；
   - 做法：检索到的优秀论文若公开关键数值，就建一张对比表（本文 / 优秀 / 偏差 / 原因分析）。偏差小 = 交叉验证通过；偏差大 = 深挖模型差异（如精确刚体链 vs 固定弧长偏移），把差异写成论据。

5. **扫描/离散化必须做收敛性验证**：峰值若陡，粗步长会严重低估——Q5 粗扫 dt=2.0 只得 1.4213（低估 11%），逐级加密到 dt=0.005 才收敛到 1.6066。凡是"扫参数找极值/临界值"，一律**粗扫定位 + 峰值窗口逐级加密直到稳定**，各档数值留档，正文用加密迭代表呈现。

6. **参考文献：优秀论文常引"经典方法文献"**（阿基米德螺线、可控 n-拖车非完整约束、Dubins 路径等）。P2 方法选型 / P5 写作时就应检索这类文献（`paper-search-mcp`），正文按"方法 → 文献"给 `\cite`，比只堆数据/报告更显学术深度。
