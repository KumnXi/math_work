# 验收清单（对应 acceptance.py 9 步）

与 `acceptance.py` 的 A1–A9 一一对应。每项给出"怎么查、常见失分点、修正动作"。

## A1 完整性
- 怎么查：`verify_manifest.py gate` 通过 + 论文/图表/结果文件齐全（`paper/main.pdf`、`figures/*.png`、`code/result_q*.json`）
- 失分点：缺图、缺结果文件
- 修正：补齐缺失产物，重新 record

## A2 文本泄漏 / 占位符
- 怎么查：正则扫 `main.tex`：空成员字段、`TODO/FIXME`、"XXX大学"、未替换的 `\membera{ }`、聊天痕迹、example.tex 残留段落
- 失分点：模板占位符未替换（直接判违规）
- 修正：替换全部封面字段；删除残留段落

## A3 数值一致性
- 怎么查：从 `code/result_q*.json` 读关键值（最优目标、预测精度等），在 `main.tex` 中匹配对应数字（±容差）
- 失分点：论文数字与程序结果不一致（评阅大忌）
- 修正：论文数字统一改为 result JSON 中的实际值

## A4 图表引用完整
- 怎么查：扫 `\includegraphics{...}` / `\ref{fig:xx}` / `\cite{...}` → 图文件存在 + latex_check 无 undefined ref/cite
- 失分点：图没被引用、引用未定义、文献未引
- 修正：补 `\ref` 或删多余图；补引用

## A5 LaTeX 编译
- 怎么查：`latex_check.py` 结果：零致命错误、overfull 盒在阈值内
- 失分点：编译有红错、页面溢出
- 修正：修复报错行；长表格用 `tabularx` 或调整列宽

## A6 模型形式化
- 怎么查：每个子问题至少一个 `\begin{equation}` 与求解方法陈述
- 失分点：只有文字描述没有数学表达式
- 修正：为每个子问题补模型公式

## A7 论文要素齐全
- 怎么查：含假设列表、符号表、灵敏度/稳定性小节、参考文献
- 失分点：缺假设/符号表/灵敏度章节
- 修正：补齐章节

## A8 格式规范
- 怎么查：摘要 1 页；**正文页数 ≤25 通过、25~30 通过但提示、>30 失败，附录不计页**（acceptance.py 自动定位 PDF 中"附录"起始页，正文=附录起页-2；无附录则 总页数-1）+ 承诺书/封面模式正确（提交用 `withoutpreface`）+ 按 `references/layout-norms-cumcm.md` 核对标题字体字号、首行缩进、单倍行距、图表公式居中、表注在图注位、表格三线表
- 失分点：页数超限（>30 页正文）、摘要超过一页、图表未居中、表注图注位置颠倒
- 修正：压缩正文；长代码/大数据表移入附录（附录不限页）；按排版规范修正 `main.tex`

## A9 代码可复现
- 怎么查：用 manifest 记录的 python 全路径重跑 `solve.py` → 输出 hash 与记录一致
- 失分点：代码与论文结果对不上
- 修正：重跑并同步结果
