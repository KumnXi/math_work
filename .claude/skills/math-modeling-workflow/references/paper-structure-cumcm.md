# 国赛 CUMCM 论文结构规范

## 页数硬约束

- 摘要**独立一页**（含关键词，3–6 个）
- 正文 **≤ 25 页**（2026 年国赛要求，以当年官方通知为准）；官方"正文尽量 ≤20 页"为**软性建议**——论据充分（每页有实质内容）优先，25~30 页可接受但须自查无注水，>30 页应精简（验收 A8 按正文页数判定）
- 附录**不计入正文页数、页数不限**（完整代码、大数据表放这里）
- 前三页固定：承诺书、编号专用页、摘要专用页；**正文不要目录**

## 章节骨架（按官方排版要求，见 `layout-norms-cumcm.md`）

```
摘要（第一段 3–4 排；精练点明中心思想/主要模型算法；每问结果必写；不插公式；无第一人称；不超过一页）
关键词（放摘要页靠底部）
一、问题重述            1.1 问题背景 / 1.2 题设数据 / 1.3 需解决的问题
                        （用自己的话转述，严禁照抄题目；不处理数据、不做图；不超过一页）
二、模型假设            （3–5 个为宜，逐条编号、严格数学语言、可检验）
三、符号说明            （不设表头；字母用公式编辑器；整张表在一页内）
四、问题分析            4.1 对问题一的分析 / 4.2 对问题二的分析
                        （先分析后建模，不出现模型公式/字母；各问不严重失衡）
五、数据分析            （只分析有用数据；图表不要竖着连续放；每个图表前后都有文字）
六、问题一的模型建立与求解
  6.1 模型的建立        （公式前 1–3 行解释；约束精简）
  6.2 模型的求解        （方法/步骤/框图/算法；答案必须放）
  6.3 结果分析          （对结果分析，可加图表非纯文字）
七、问题二的模型建立与求解  （每个问题一个一级标题，同上结构）
八、模型的评价          8.1 模型的优点 / 8.2 模型的缺点（优点条数 > 缺点条数）
九、模型的改进与推广     （先评价→再改进→后推广；改进针对缺点逐条）
参考文献               （GB/T 7714，知网导入真实文献）
附录                   （完整可运行程序、大数据表；国赛要求压缩后 ≤20MB）
```

> 注：误差分析 / 模型检验 / 灵敏度分析须**基于数据**、不纯文字，可作为各问题求解后的分析小节，或置于评价之前。
> 排版细节（标题字体字号、首行缩进、单倍行距、图表公式居中、表注图注位置、不用目录）统一见 `layout-norms-cumcm.md`。

## 摘要写法（最重要，权重极高）

五段式"总分总"：
1. 问题背景 + 总体思路
2. 针对问题一：模型 + 算法 + **具体数值结果**
3. 针对问题二：同上
4. 针对问题三/四：同上
5. 模型特点（灵敏度、稳定性、创新点）+ 推广

要求：不出现公式；不出现第一人称；可用"针对问题 1……针对问题 2……"串联；模型名/方法名必须出现在关键词中。

## 模型假设规范

- 每条假设必须：严格数学语言表述、为建模所必需、合理性可检验
- 关键假设不能缺；不宜过多过细（一般为 3–8 条）

## 结果分析写法

- 不只重复数据，要**结合数据解释结果差异产生的原因**（为什么这个方案/参数下得分更高）
- 说明结果的**实际指导价值**（对决策者意味着什么、如何落地）
- 可用图表支撑（对比图、误差带、分布），非纯文字

## 公式规范

- 每个公式用 `\begin{equation}...\label{eq:xx}\end{equation}` 编号
- 每个公式须说明作用，所有符号已定义（与符号表对应）
- 用三线表（booktabs）做表格，勿用竖线

## 图规范

- 图有题号、标题、坐标轴单位、数据来源
- 正文必须用 `\ref{fig:xx}` 引用到每张图
- 导出 300dpi 以上；中文用 SimHei 字体（matplotlib 设 `rcParams['font.sans-serif']=['SimHei']`，`axes.unicode_minus=False`）

## 参考文献（GB/T 7714）

```
[1] 姜启源, 谢金星, 叶俊. 数学模型[M]. 5版. 北京: 高等教育出版社, 2018.
[2] Author, A. B., Author, C. D. Title of paper[J]. Journal Name, 2020, 12(3): 45-60.
```
美赛建议 15–20 篇；国赛引用的文献必须真实可查——用 `paper-search-mcp` 检索本问方法文献 + DOI 反查核对，禁止编造，方法见 `paper-search-literature.md`。

## 承诺书 / 封面模式

- 电子提交（无纸质承诺书场景）用 `\documentclass[withoutpreface,bwprint]{cumcmthesis}`
- 打印版默认模式保留承诺书页
- 封面字段：`\tihao`（题号）`\schoolname` `\membera/b/c`（队员）`\supervisor`（指导教师）`\yearinput` `\monthinput` `\dayinput`

## 常见失分点

- 摘要没有具体数值结果 / 超一页
- 问题重述照抄题目
- 符号表缺失、一个符号多义
- 灵敏度分析缺失或流于形式
- 图表无编号无引用、表格带竖线
- 页数超限、参考文献格式错误
